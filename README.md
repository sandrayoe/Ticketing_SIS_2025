# Ticketing_SIS_2025
Deploying simple site for ticketing and registration of SIS Event 2025
//README last edited - 22/9/2025

Pages:
1. Homepage for general info
2. About - just a container about the event and SIS
3. Register form - Data fillings, payment info, live calculator, and submit
4. Success - a notice that the data has been received, invoice sent, and up to 48 hrs for the tickets
5. Admin only - issue tickets in batches
6. Admin - checkin - to checkin using the QR and manual input of number (PM25-XXX)
7. Admin - manual-register - d-day register page without needing to submit payment proof

Features:
1. Automatic invoice to the registrans email
2. (supposedly) automatic payment proofs check using OCR when the tickets are issued in batches. Unfortunately, the file cannot be too large for now.
3. Issued tickets contain numbers (PM25XXX) and QR
